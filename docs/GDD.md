## 1. Видение и концепт

### 1.1 Что такое Dragon Dice

Dragon Dice — мини-игра в кости внутри экосистемы Dragon Family World. Основана на классических правилах Yahtzee с адаптацией для детской аудитории. Игроки бросают 5 кубиков, выбирают какие оставить, и заполняют таблицу из 13 категорий очков за 13 раундов. Побеждает игрок с наибольшим итоговым счётом.

### 1.2 Зачем

Dragon Dice — первая мини-игра в разделе «Игры» Dragon Family. Она решает три задачи одновременно: удерживает детей в приложении (ежедневный возврат), генерирует доход (IAP + реклама), и конвертирует бесплатных пользователей в подписчиков Dragon Family.

### 1.3 Pillars of the Game

| Pillar | Что это значит для Dragon Dice |
|---|---|
| **Education** | Тренировка счёта, вероятностного мышления, стратегического принятия решений. Дети учатся оценивать риски и делать выбор в условиях неопределённости. |
| **Company** | Совместная игра с семьёй и друзьями. Дети и взрослые соревнуются на равных — Yahtzee уравнивает шансы за счёт элемента удачи. |
| **Fun** | Яркая драконья тематика, коллекционирование скинов, соревнования и достижения. Каждая партия — маленькое приключение. |

### 1.4 Тон и атмосфера

Дружелюбный, волшебный, драконий мир. Всё должно ощущаться как приключение с драконами, но без излишней сложности и агрессии. Дракон-помощник Гаврик сопровождает игрока, подсказывает и радуется удачным комбинациям.

### 1.5 Отличие от конкурентов

В Dragon Dice дети и взрослые соревнуются на равных, прокачивают не только Гаврика, но и свои мозги. Игроков ждёт увлекательный мир вероятностей и удачи — с наградами, которые переносятся в основное приложение Dragon Family.

### 1.6 Сводка

| Параметр | Значение |
|---|---|
| Жанр | Dice game, strategy |
| Платформа | Web (mobile-first, responsive) |
| Игроки | 2–4 онлайн, 2–6 локально |
| Сессия | ~15–25 минут (полная), ~8–12 минут (быстрый режим) |
| Языки | English, Русский |
| Монетизация | Freemium + IAP + Rewarded Ads + Subscription Driver |

## 2. Целевая аудитория

### 2.1 Основная аудитория

Дети 8+ лет и их семьи. Трафик приходит из основного приложения Dragon Family (100K+ MAU).

### 2.2 Персоны

| Персона | Возраст | Сценарий | Мотивация | Платёжное поведение |
|---|---|---|---|---|
| **Маша** | 9 лет | Играет с мамой по вечерам, собирает скины кубиков | Коллекционирование, совместное время | Просит маму купить скин |
| **Артём** | 12 лет | Соревнуется с друзьями, гонится за рейтингом | Конкуренция, статус, достижения | Смотрит рекламу за бонусы |
| **Папа Дима** | 35 лет | Играет с детьми в семейном режиме | Качественное время с семьёй | Оплачивает подписку Dragon Family |
| **Лена** | 10 лет | Играет с ботами по дороге в школу | Быстрое развлечение, прогрессия | Бесплатный игрок, потенциальный подписчик |

### 2.3 Сценарии использования

- **«5 минут перед сном»** — быстрая партия с ботом, забрать ежедневную награду
- **«Семейный вечер»** — 3–4 игрока локально на планшете
- **«Переменка в школе»** — онлайн-партия с другом по коду комнаты
- **«Дорога в школу»** — партия с ботом в быстром режиме
- **«Выходной турнир»** — серия рейтинговых партий за недельные призы

## 3. Геймплей

### 3.1 Core Loop

```
Вход в Dragon Dice
  → Забрать ежедневную награду (Драконий календарь)
  → Проверить задания
  → Создать / присоединиться к партии
    → Лобби (ожидание игроков)
    → Игра (13 раундов)
      → Бросок → Удержание → Переброс → Выбор категории
    → Результаты + награды
  → Вернуться за следующей партией / выйти в Dragon Family
```

### 3.2 Создание и присоединение

- Хост создаёт комнату → получает 6-символьный код (алфавит: `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`, без путающих символов: I, O, 0, 1).
- Другие игроки вводят код или переходят по ссылке.
- Аутентификация не требуется внутри Dragon Dice — используется user_id из Dragon Family.
- При дубликате display name автоматически добавляется суффикс (" 2", " 3"...).
- Кнопка "Play with Bots" — быстрый старт без ожидания.

### 3.3 Лобби

- Хост видит список присоединившихся игроков.
- Хост может добавить AI-ботов (до max_players суммарно).
- Хост нажимает "Start Game" → игра начинается для всех одновременно.
- Минимум 2 игрока для старта.
- Кнопка "Share" — копирует код/ссылку (`navigator.share` API на мобильных).

### 3.4 Ход игрока (Turn)

```
Бросок 1 (автоматический, все 5 кубиков)
  → Игрок выбирает кубики для удержания (hold)
  → Бросок 2 (перебрасываются только не удержанные)
  → Игрок корректирует удержание
  → Бросок 3 (финальный)
  → Игрок выбирает категорию для записи очков
```

1. Игрок бросает 5 кубиков (автоматический первый бросок).
2. Выбирает какие кубики «удержать» (hold) — они не будут перебрасываться.
3. Перебрасывает оставшиеся кубики (до 3 бросков за ход).
4. После любого броска (включая первый) может выбрать категорию для записи очков.
5. Выбор категории обязателен — ход не заканчивается, пока категория не выбрана.
6. После выбора категории ход переходит к следующему игроку.

### 3.5 Кубики

- 5 стандартных шестигранных кубиков (значения 1–6).
- Генерация: `Math.floor(Math.random() * 6) + 1`.
- Визуализация: кнопки с точками (pip dots), расположенными по классическому шаблону кубика.
- Удержанные кубики визуально выделяются: синяя рамка + значок "H".
- Hold недоступен до первого броска, сбрасывается при начале нового хода.
- Анимация: CSS-класс `dice-rolling` при броске.

### 3.6 Раунды

- Всего 13 раундов (по числу категорий).
- В каждом раунде каждый игрок делает один ход.
- Порядок ходов фиксирован (по `player_index`: 0, 1, 2, 3).
- Игра заканчивается, когда все 13 категорий заполнены у всех игроков.

### 3.7 Особенности UX для детей

- **Подсветка зелёным** — категории, в которые можно записать ненулевой результат.
- **Прогресс до бонуса** — «Осталось 11 до +35!» в верхней секции.
- **Подсказка после броска** — «Можно записать сюда → +XX очков» (выделено цветом).
- **Рекомендация при нуле** — если некуда записать выгодно, подсказка рекомендует категорию для 0 (предпочитая Yahtzee или редко используемую ячейку).
- **Кнопка «Правила»** — всегда доступна, краткий текст + иллюстрации.
- **Кнопка «Вероятности и советы»** — простые объяснения с картинками.

## 4. Система очков

### 4.1 Верхняя секция (6 категорий)

| Категория | Правило | Макс. очков |
|---|---|---|
| Ones (Единицы) | Сумма всех кубиков со значением 1 | 5 |
| Twos (Двойки) | Сумма всех кубиков со значением 2 | 10 |
| Threes (Тройки) | Сумма всех кубиков со значением 3 | 15 |
| Fours (Четвёрки) | Сумма всех кубиков со значением 4 | 20 |
| Fives (Пятёрки) | Сумма всех кубиков со значением 5 | 25 |
| Sixes (Шестёрки) | Сумма всех кубиков со значением 6 | 30 |

**Upper Bonus**: +35 очков, если сумма верхней секции ≥ 63.

> Подсказка для игрока: 63 = 3 × (1+2+3+4+5+6). Нужно в среднем по 3 совпадения на категорию.

### 4.2 Нижняя секция (7 категорий)

| Категория | Правило | Очков |
|---|---|---|
| Three of a Kind (Тройка) | 3+ одинаковых → сумма ВСЕХ кубиков | 5–30 |
| Four of a Kind (Каре) | 4+ одинаковых → сумма ВСЕХ кубиков | 5–30 |
| Full House (Фулл-хаус) | 3 одинаковых + 2 одинаковых | 25 |
| Small Straight (Малый стрит) | 4 последовательных (1-2-3-4, 2-3-4-5, 3-4-5-6) | 30 |
| Large Straight (Большой стрит) | 5 последовательных (1-2-3-4-5 или 2-3-4-5-6) | 40 |
| Yahtzee (Яцзы) | 5 одинаковых | 50 |
| Chance (Шанс) | Сумма всех кубиков (без условий) | 5–30 |

### 4.3 Подсчёт итога

```
Grand Total = Upper Total + Upper Bonus (0 или 35) + Lower Total
```

### 4.4 Запись нуля

Игрок может записать 0 очков в любую незаполненную категорию, если текущий бросок не подходит ни под одну выгодную категорию. Это стратегическое решение — «пожертвовать» слабой категорией.

## 6. Обучение и онбординг

### 6.1 Интерактивный туториал

- Первая игра → обязательный интерактивный туториал (4–6 ходов).
- Пошаговые подсказки с анимированным драконом-помощником Гавриком.
- Фокус: бросок → удержание → выбор категории → понимание очков.
- Туториал можно пройти заново из меню настроек.
- Туториал не считается партией (не тратит бесплатную партию).

### 6.2 Подсказки в игре

- **Подсветка зелёным** — комбинации, в которые можно записать сейчас.
- **Прогресс до бонуса** — «Осталось 11 до +35!» в верхней секции.
- **Подсказка после броска** — «Можно записать сюда → +XX очков» (выделено цветом).
- **Рекомендация при нуле** — если некуда записать выгодно, подсказка рекомендует категорию для 0.

### 6.3 Справка

- Кнопка «Правила игры» — краткий текст + иллюстрации (доступна всегда).
- Кнопка «Вероятности и советы» — простые объяснения с картинками (пример: «Шанс выбить Yahtzee с первого броска ≈ 1 к 7776»).

## 7. Монетизация

### 7.1 Модель

Freemium с 4 источниками дохода. Все покупки проходят через **родительский гейт** (COPPA/GDPR-K requirement). Никакие покупки не дают игрового преимущества (pay-to-win) — только косметика и удобство.

### 7.2 Столп 1: Энерджи-система + Rewarded Ads

Основной механизм конверсии — ограничение бесплатных партий с возможностью разблокировки через рекламу.

**Для бесплатных игроков:**

| Параметр | Значение |
|---|---|
| Бесплатные партии | 1 партия в час |
| Восстановление | Час отсчитывается с момента начала предыдущей бесплатной партии |
| Разблокировка рекламой | 1 реклама = 1 дополнительная партия |
| Лимит рекламы в день | 5 просмотров (COPPA-лимит) |

**Для подписчиков Dragon Family:**

| Параметр | Значение |
|---|---|
| Партии | Неограниченно |
| Rewarded ads (опционально) | Дополнительный (4-й) бросок кубика в ходе |
| Rewarded ads (опционально) | Удвоение монет Dragon Family за партию |
| Rewarded ads (опционально) | Бесплатная заморозка Драконьего календаря |

**Требования COPPA для рекламы:**
- Только COPPA-compliant рекламные сети (без трекинга, без таргетирования)
- Контекстная реклама, не персонализированная
- Родительский гейт перед первым просмотром рекламы в сессии

### 7.3 Столп 2: Косметика (IAP)

Прямые покупки косметических предметов, не влияющих на геймплей.

| Категория | Примеры | Цена |
|---|---|---|
| Скины кубиков (обычные) | Деревянные, каменные, стеклянные | $0.99 |
| Скины кубиков (редкие) | Огненные, ледяные, золотые | $1.99 |
| Скины кубиков (легендарные) | Драконье яйцо, кристалл, звёздная пыль | $2.99 |
| Фоны игрового стола | Пещера дракона, облачный замок, подводный мир | $1.99 |
| Наборы звуков | Огненный бросок, ледяной звон, магический | $0.99 |
| Тематические бандлы | Скин + фон + звук | $3.99–$4.99 |

Все покупки проходят через родительский гейт (математическая задача или текстовый пароль).

### 7.4 Столп 3: Драйвер подписки Dragon Family

Подписчики Dragon Family получают в Dragon Dice:

- **Неограниченное количество партий** (главное преимущество)
- Премиум-дорожку Сезонов дракона (см. раздел 8.2)
- 3 заморозки streak-календаря в неделю (вместо 1)
- Эксклюзивный анимированный скин кубика каждый месяц
- Дополнительные ежедневные монеты Dragon Family (×2)

> **Стратегическая цель**: не прямой доход из Dragon Dice, а конверсия бесплатных пользователей в подписку основного приложения. Dragon Dice как «вкус подписки» — ребёнок испытывает ограничение, видит что подписчики играют сколько хотят, и мотивирует родителя подписаться.

### 7.5 Столп 4: Турниры (v2.0)

- Вход в турнир за внутриигровую валюту Dragon Family
- Возможность покупки валюты за реальные деньги (через родительский гейт)
- Призовой фонд — эксклюзивная косметика (скины, фоны, звуки)
- Еженедельные турниры с лидербордами

### 7.6 Чего мы НЕ делаем

- ❌ Никакого pay-to-win (покупки не дают игрового преимущества)
- ❌ Никакой навязчивой рекламы (только по инициативе игрока)
- ❌ Никаких лутбоксов (все покупки прозрачны, известно что получаешь)
- ❌ Никакого FOMO на платный контент для детей до 13 (COPPA best practice)
- ❌ Никаких социальных давлений к покупке («Твой друг купил! А ты?»)

## 8. Удержание и вовлечение (Retention)

### 8.1 Драконий календарь (Daily Login Rewards)

Система ежедневных наград с streak-механикой — основной драйвер D1 retention.

**Механика:**
- Каждый день игрок заходит в Dragon Dice и получает награду.
- Награды растут по мере продолжения streak (1-й день — малая, 7-й — крупная).
- Пропуск дня **сбрасывает streak**.
- 1 бесплатная «заморозка» в неделю (пропуск не сбрасывает streak).
- Подписчики Dragon Family: 3 заморозки в неделю.

**Таблица наград:**

| День streak | Награда (бесплатная) | Награда (подписчик) |
|---|---|---|
| День 1 | 10 монет DF | 20 монет DF |
| День 2 | 15 монет DF | 30 монет DF |
| День 3 | 20 монет DF + фрагмент скина (1/3) | 40 монет DF + фрагмент скина (1/3) |
| День 4 | 25 монет DF | 50 монет DF |
| День 5 | 30 монет DF + фрагмент скина (2/3) | 60 монет DF + фрагмент скина (2/3) |
| День 6 | 35 монет DF | 70 монет DF |
| День 7 | 50 монет DF + полный скин! | 100 монет DF + редкий скин + предмет для дракона |

После 7-го дня цикл перезапускается с новым набором наград.

### 8.2 Сезоны дракона (Battle Pass)

Ежемесячные тематические сезоны с двухдорожечной системой прогрессии — драйвер D30 retention и подписки.

**Механика:**
- Каждый месяц — новая тема (например: «Огненный сезон», «Ледяной дракон», «Изумрудный турнир»).
- За каждую партию игрок получает очки сезона (Season XP).
- Базово: +10 XP за партию, +5 бонус за победу, +2 за каждый Yahtzee.
- Набирая пороги XP, игрок открывает награды.

**Две дорожки:**

| Уровень | Бесплатная дорожка | Премиум дорожка (подписчики / $2.99) |
|---|---|---|
| 5 | 50 монет DF | Обычный скин кубика (сезонный) |
| 10 | Аватарка (сезонная) | 150 монет DF |
| 15 | 100 монет DF | Анимированный скин кубика |
| 20 | Обычный фон стола | Уникальный набор звуков |
| 25 | 150 монет DF | Редкий фон стола (сезонный) |
| 30 | Титул (сезонный) | Легендарный скин кубика + предмет для дракона в DF |

**Сроки:** 30 дней на сезон. Не успел — награды уходят навсегда (FOMO-механика).

### 8.3 Ежедневные и еженедельные задания

**Ежедневные задания (3 штуки, обновляются в полночь):**

Примеры:
- «Сыграй 2 партии» → 15 монет DF
- «Собери Yahtzee» → 25 монет DF + 10 Season XP
- «Набери 200+ очков за партию» → 20 монет DF
- «Получи бонус верхней секции (+35)» → 30 монет DF

**Еженедельные вызовы (1 штука, обновляется в понедельник):**

Примеры:
- «Сыграй 10 партий за неделю» → Редкий фрагмент скина
- «Набери суммарно 1500 очков» → 100 монет DF
- «Собери 3 Full House за неделю» → Уникальная аватарка

### 8.4 Рейтинги и статистика

- **Личный рейтинг** — ELO-подобная система для онлайн-мультиплеера
- **Глобальный топ** — лучшие игроки за неделю / месяц
- **Статистика игрока**: всего партий, побед, Yahtzee, средний счёт, лучший счёт, процент получения бонуса верхней секции
- **Достижения** — коллекционная система бейджей (первый Yahtzee, 100 партий, победа с счётом 300+, и т.д.)

### 8.5 Retention-петли по горизонтам

| Горизонт | Что возвращает игрока | Механика |
|---|---|---|
| **1 час** | «Жизнь восстановилась» | Энерджи-система (1 бесплатная партия/час) |
| **1 день** | «Забери награду, не потеряй streak» | Драконий календарь |
| **1 неделя** | «Еженедельный вызов, закрой недельную цель» | Еженедельные задания |
| **1 месяц** | «Новый сезон с уникальными наградами» | Сезоны дракона |

## 9. Социальные механики

### 9.1 Друзья

- Добавление друзей по никнейму (без обмена персональными данными — COPPA-compliant).
- Список друзей с индикатором онлайн/оффлайн.
- Быстрое приглашение друга в партию.
- Друзья синхронизируются с системой друзей Dragon Family.

### 9.2 Вызовы (Challenges)

- Игрок может отправить другу вызов: «Побей мой рекорд 287 очков!»
- Друг получает уведомление в Dragon Family.
- Если побеждает — **оба** получают бонусные монеты (поощряем взаимодействие, а не только победу).
- Лимит: 3 вызова в день (анти-спам).
- Вызов действует 24 часа.

### 9.3 Семейный режим

- Родитель и ребёнок играют вместе.
- Общая таблица лидеров семьи (Dragon Family household).
- Семейные достижения: «Сыграли 50 партий вместе», «Мама и сын оба набрали 250+».
- Семейный streak: если хотя бы один член семьи зашёл — streak сохраняется.
- Усиливает позиционирование Dragon Family как семейного приложения.

### 9.4 Ограничения (COPPA)

- Никакого свободного текстового чата — только предустановленные эмодзи-реакции.
- Вызовы отправляются через систему Dragon Family (не через внешние сервисы).
- Родитель может отключить социальные функции в настройках Dragon Family.

## 14. Мультиплеерная архитектура

### 14.1 Комнаты

- Код комнаты: 6 символов, алфавит `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`.
- Максимум 4 игрока (онлайн).
- Статусы комнаты: `lobby` → `playing` → `finished`.
- Автоматическое удаление через 24 часа неактивности (`expires_at`).

### 14.2 Realtime-синхронизация

Канал: `game:room:{roomCode}`

**Broadcast-события:**

| Событие | Payload | Когда |
|---|---|---|
| `dice_roll` | dice, rollCount, availableCategories, playerIndex | Игрок бросил кубики |
| `score_update` | category, score, playerIndex, scorecard | Игрок выбрал категорию |
| `game_start` | players, turnOrder, firstPlayerIndex | Хост запустил игру |
| `game_end` | winner, finalScores | Все категории заполнены |
| `player_joined` | player info | Новый игрок в лобби |
| `player_left` | playerIndex | Игрок покинул |
| `turn_skipped` | playerIndex, category | Авто-скип отключённого |

### 14.3 Presence (Присутствие)

Канал: `presence:{roomCode}`

- Отслеживает online/offline статус каждого игрока.
- При потере соединения: 30-секундный таймаут.
- Если игрок не вернулся — авто-скип хода (0 очков в первую незаполненную категорию).
- Передача роли хоста: если хост отключается, следующий подключённый игрок становится хостом.

### 14.4 Reconnection

- Игрок может вернуться по той же ссылке.
- Session ID сохраняется в localStorage.
- При повторном входе с тем же session_id → восстановление в игру (rejoin).

## 15. AI-бот

### 15.1 Стратегия выбора кубиков для удержания (chooseDiceToHold)

| Целевая категория | Логика |
|---|---|
| Upper (ones–sixes) | Удерживать кубики с соответствующим значением |
| Three/Four of a Kind, Yahtzee | Удерживать наиболее часто встречающееся значение |
| Full House | Удерживать два наиболее частых значения |
| Small/Large Straight | Удерживать уникальные значения, отпускать дубликаты |
| Chance | Удерживать высокие значения (4, 5, 6) |

### 15.2 Решение о переброске (shouldReroll)

- Остановиться, если 3 броска использованы.
- Остановиться, если «marginal value» ≥ 80% (score / maxPossible).
- Иначе — перебросить для улучшения результата.

### 15.3 Выбор категории (chooseCategory)

1. Рассчитать marginal value для каждой доступной категории.
2. Выбрать категорию с наибольшим marginal value.
3. При равенстве — предпочитать более высокий абсолютный счёт.
4. Если все доступные категории дают 0 очков — «пожертвовать» категорией с наименьшим максимумом.

### 15.4 Тайминги бота

| Действие | Задержка |
|---|---|
| Первый бросок | 1000 мс |
| Последующие броски | 600 мс |
| Следующий ход бота | 500 мс |
